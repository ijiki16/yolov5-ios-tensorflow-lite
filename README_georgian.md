# YOLOv5 iOS TensorFlow Lite

[English README](README.md) | [한국어 README](README_korean.md)

ეს არის iOS აპლიკაციის მაგალითი, რომელიც ობიექტებს რეალურ დროში ამოიცნობს TensorFlow Lite ფორმატში გადაყვანილი [YOLOv5](https://github.com/ultralytics/yolov5) მოდელის გამოყენებით. აპლიკაცია მოწყობილობის უკანა კამერის გამოსახულებაზე აჩვენებს შემომსაზღვრელ ჩარჩოებს (bounding box), კლასებს და სანდოობის მაჩვენებელს. მოდელი GPU-ზე სრულდება TensorFlow Lite-ის Metal delegate-ის მეშვეობით, ხოლო თუ delegate-ის შექმნა ვერ მოხერხდა, ავტომატურად გადადის CPU-ზე.

**მხარდაჭერილი iOS ვერსია:** iOS 12.0 და ზემოთ.
**საჭირო Xcode:** Xcode-ის ახალი ვერსია Swift 5-ის მხარდაჭერით.

## წინასწარი მოთხოვნები

* Xcode და მისი command-line ხელსაწყოები: `xcode-select --install`. თუ Xcode ახლახან დააინსტალირეთ, ერთხელ გახსენით და დაეთანხმეთ ლიცენზიას.

* [CocoaPods](https://cocoapods.org): `sudo gem install cocoapods`. TensorFlow-ის აწყობა თქვენით არ გჭირდებათ, CocoaPods თავად ჩამოტვირთავს TensorFlow Lite ბიბლიოთეკას. პირველი `pod install` გადმოწერს TensorFlow-ის მთელ რეპოზიტორიას Swift-ის კოდისთვის, ამიტომ შეიძლება დიდხანს გაგრძელდეს.

* Apple Developer ანგარიში, რეალურ მოწყობილობაზე გასაშვებად.

* რეალური iOS მოწყობილობა. აპლიკაციას კამერა სჭირდება. სიმულატორზე აპლიკაცია აიწყობა და ჩაირთვება, მაგრამ კამერის არარსებობის გამო აჩვენებს „Configuration Failed" შეტყობინებას.

## აწყობა და გაშვება

1. დააინსტალირეთ pod-ები workspace-ის შესაქმნელად:

   ```sh
   cd yolov5-ios-tensorflow-lite/
   pod install
   ```

   თუ pod-ები ადრე უკვე გქონდათ დაინსტალირებული და ეს ბრძანება არ მუშაობს, სცადეთ `pod update`.

2. მოამზადეთ ხელმოწერის (signing) პარამეტრები. დააკოპირეთ მაგალითის ფაილი და ჩაწერეთ თქვენი Team ID და უნიკალური Bundle Identifier:

   ```sh
   cp Config/Local.xcconfig.example Config/Local.xcconfig
   ```

   `Config/Local.xcconfig` git-ის მიერ იგნორირებულია, ამიტომ თქვენი პირადი ხელმოწერის მონაცემები არასდროს მოხვდება commit-ში.

3. გახსენით **ObjectDetection.xcworkspace** (და არა `.xcodeproj`) Xcode-ში.

4. ააწყვეთ და გაუშვით რეალურ მოწყობილობაზე. მიეცით აპლიკაციას კამერაზე წვდომის უფლება და მიმართეთ კამერა ობიექტებისკენ.

## მოდელები

[ObjectDetection/Model](ObjectDetection/Model) საქაღალდეში ჩართულია COCO მონაცემებზე გაწვრთნილი ორი YOLOv5 მოდელი:

| ფაილი | აღწერა |
| --- | --- |
| `yolov5s-fp16.tflite` | პატარა (small) მოდელი. უფრო ზუსტია, მაგრამ უფრო ნელი. **გამოიყენება ნაგულისხმევად.** |
| `yolov5n-fp16.tflite` | ნანო (nano) მოდელი. ნაკლებად ზუსტია, მაგრამ უფრო სწრაფი. |

გადასართავად [ModelDataHandler.swift](ObjectDetection/ModelDataHandler/ModelDataHandler.swift)-ში შეცვალეთ `Yolov5.modelInfo` მნიშვნელობით `Yolov5.nanoModelInfo`.

### მოდელის შესავალი და გამოსავალი

აპლიკაცია მოდელის ჩატვირთვისას კითხულობს ტენზორების ფორმებს და უარს ამბობს შეუსაბამო მოდელის ჩატვირთვაზე:

* **შესავალი:** `[1, height, width, 3]`, RGB, float, მნიშვნელობები `[0, 1]` დიაპაზონშია. ჩართული მოდელები იყენებენ `640 x 640` ზომას. კამერის კადრი მასშტაბირდება პროპორციების შენარჩუნებით და ღია რუხი ფერით ივსება დარჩენილი ადგილი (letterbox), ხოლო ჩარჩოები შემდეგ ისევ ორიგინალ კადრზე გადაითვლება.
* **გამოსავალი:** `[1, rows, 5 + კლასების რაოდენობა]`. თითოეული სტრიქონია `x, y, w, h, objectness, კლასების ქულები...`, სადაც ჩარჩო ნორმალიზებულია შესავლის ზომაზე. ჩართული მოდელები იძლევა `[1, 25200, 85]`-ს (80 COCO კლასი).

### საკუთარი მოდელის გამოყენება

1. გააწვრთნეთ YOLOv5 მოდელი და გადაიყვანეთ TensorFlow Lite ფორმატში [YOLOv5 რეპოზიტორიის](https://github.com/ultralytics/yolov5) `export.py`-ით:

   ```sh
   python export.py --weights your_model.pt --include tflite
   ```

2. დაამატეთ `.tflite` ფაილი `ObjectDetection/Model`-ში და ჩართეთ Xcode-ის target-ში.
3. ჩაანაცვლეთ `classes.txt` თქვენი კლასების სახელებით, თითო ხაზზე ერთი, ტრენინგის დროინდელი თანმიმდევრობით. ლეიბლების რაოდენობა არ უნდა იყოს მოდელის კლასების რაოდენობაზე ნაკლები.
4. `Yolov5.modelInfo` მიუთითეთ თქვენს მოდელზე.

### ამოცნობის პარამეტრების მორგება

ზღვრები მოცემულია [PrePostProcessor.swift](ObjectDetection/Utils/PrePostProcessor.swift)-ში:

* `confidenceThreshold` (ნაგულისხმევად `0.25`): ამოცნობისთვის საჭირო მინიმალური `objectness * კლასის ქულა`.
* `iouThreshold` (ნაგულისხმევად `0.45`): გადაფარვის დონე, რომელზე მეტის შემთხვევაშიც ერთი და იმავე კლასის დაბალქულიანი ჩარჩო იშლება.
* `nmsLimit` (ნაგულისხმევად `100`): ამოცნობების მაქსიმალური რაოდენობა ერთ კადრზე.

## აპლიკაციის დეტალები

აპლიკაცია მთლიანად დაწერილია Swift-ზე და იყენებს TensorFlow Lite-ის [Swift ბიბლიოთეკას](https://github.com/tensorflow/tensorflow/tree/master/tensorflow/lite/swift) (ვერსია 2.17, Metal delegate-ით).

* ინფერენსი საკუთარ სერიულ რიგში (queue) სრულდება. თუ წინა კადრი ჯერ კიდევ მუშავდება, ახალი კადრები გამოტოვებულია, ხოლო ინფერენსი შეზღუდულია მაქსიმუმ ერთ გაშვებამდე ყოველ 200 მილიწამში.
* როცა GPU delegate აქტიურია, ქვედა პანელის thread-ების რაოდენობის სტეპერს გავლენა არ აქვს; ის მხოლოდ CPU-ზე გადასვლის შემთხვევაში მუშაობს.
